# 視覺與內容方向

這份履歷參考下列網站的資訊呈現方式，沒有複製其程式碼、文字、品牌或版型：

- [Brittany Chiang](https://brittanychiang.com/)：清楚的職務定位、可掃讀的工作經歷、具體的專案內容。
- [Lee Robinson](https://leerob.com/)：精簡自我介紹與文字優先的個人網站。

這些是設計參考，並非「大多數人都使用」的統計依據。新版取其清楚、易讀的原則，依繁體中文履歷需要重新排版。

## 配色

| 用途 | 色碼 |
| --- | --- |
| 主背景 | `#FFFFFF` |
| 主要文字 | `#181D27` |
| 次要文字 | `#596373` |
| 連結與主要按鈕 | `#315BE8` |
| 輔助區塊 | `#F7F8FB` |
| 分隔線 | `#E6E9EF` |

以白色、深灰與少量藍色建立閱讀層次。首頁使用清楚、自然彩色的大頭照，不加浮動標籤或裝飾濾鏡。內容沿著一條會隨滾動填色的時間線，依序展開研究所、友達、大學與聯絡章節；固定的「目前閱讀」標籤與導覽狀態同步更新，讓長頁面仍能辨識所在階段。避免廣告式文案、過多漸層及沒有資訊意義的進場動畫。

手機將照片縮至姓名旁，主要內容使用單欄，導覽收合；桌機使用完整簡介與三欄專案，平板改兩欄。支援 reduced-motion、鍵盤操作與 A4 列印。

研究所狀態、校名、系所與研究方向依本人於 2026 年 10 月 23 日提供的資訊呈現；未提供的入學年月不自行推測。
