## 配色

| 用途 | 色碼 |
| --- | --- |
| 主背景 | `#FFFFFF` |
| 主要文字 | `#181D27` |
| 次要文字 | `#596373` |
| 連結與主要按鈕 | `#315BE8` |
| 輔助區塊 | `#F7F8FB` |
| 分隔線 | `#E6E9EF` |

以白底與深灰建立閱讀層次，藍色僅用於導引、按鈕與少量成果重點。照片保留原本彩色，不使用黑白濾鏡或混色。避免傾斜卡片、巨幅廣告標語、無實際資料的圖表及裝飾動畫。

手機將照片縮至姓名旁，主要內容使用單欄，導覽收合；桌機使用完整簡介與三欄專案，平板改兩欄。支援 reduced-motion、鍵盤操作與 A4 列印。
